# Contributing to agent007

Use Node.js 24 or later and run `npm test` before submitting a pull request. Start the app with `npm start` to try workflow and interface changes in the browser.

- Describe the problem or workflow you want to improve and how you verified the change.
- Include a small, synthetic workflow for changes that affect execution or approvals.
- Keep approval decisions and run events visible in the execution history.
- Use placeholders for credentials and fictional data in examples, fixtures, screenshots, and issue reports.
